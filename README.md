# airshift-site

Coming soon page for [airshift.ai](https://airshift.ai), hosted on GitHub Pages from `main`.

## Preview locally

```bash
./serve.sh        # http://localhost:4000
./serve.sh 5000   # another port
```

## Publish

Commit and push to `main`; GitHub Pages redeploys in about a minute.
Pushes must use the `csarat` GitHub account (`gh auth switch --user csarat` if `csarat-bp` is active).
